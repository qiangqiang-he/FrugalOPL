- `[x]` 表示正式实验已完成；`[ ]` 配合“运行中／启动中／待运行”区分状态。双卡小批量验证通过单独记录，不计作正式实验完成。

本清单沿用你本次使用的 **TCA** 名称。仓库中的对应实现、配置目录及历史 SwanLab run 名仍为 `TRA` / `tra_*`；本次保留这些入口以延续已有实验。TCA 默认特权是**当前题目及其完整 solution 构成的同题 one-shot**，目标为 `r ∝ p × (p/q)^n`，默认 `n=1`、支持集阈值 `0.01`。FKL 和 Clip-OPSD 主实验使用相同的同题 solution one-shot。

三种主实验均为 No thinking、top-k 512、训练 100 steps、全局 batch 32 题 × 每题 8 个回复；训练生成上限 8192，评测上限 32768，初始及每 10 步依次评测 AMC23、AIME24（Avg@16），每 10 步保存 LoRA。FKL 和 Clip-OPSD 的 Qwen3-1.7B 使用四卡，Qwen3-4B 和 Qwen3-8B 使用八卡；TCA 使用八卡。

实验统一使用连续编号 **01–16**，编号直接写在每项标题中，例如「编号 01｜Qwen3-1.7B｜TCA」，跨章节不重置。

答案类特权今后统一使用**单轮 user 提示**，不构成 one-shot；历史已完成实验保留其实际运行版本。训练集在抽样前剔除缺失、null 或空白 answer 的记录。

## 启动前设置

在训练服务器激活环境并进入项目根目录，替换下面的路径：

```bash
export FRUGALOPL_PYTHON="$(command -v python)"
export FRUGALOPL_MODELS_ROOT="/path/to/models"
export FRUGALOPL_SWANLAB_ENV_FILE="/path/outside/repo/swanlab.env"
```

下列四卡、八卡正式命令均以 `--no-tmux` 前台运行；编号 13 的双卡训练通过 `--tmux` 托管。SwanLab 使用公开的 TCPO Project，group 为模型名称。已完成项的命令供查阅；运行中的实验按现有 run 继续。
