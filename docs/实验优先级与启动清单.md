## 启动前设置

先激活服务器上的训练环境，在项目根目录设置以下变量，并将示例路径替换为实际位置：

```bash
export FRUGALOPL_PYTHON="$(command -v python)"
export FRUGALOPL_MODELS_ROOT="/path/to/models"
export FRUGALOPL_SWANLAB_ENV_FILE="/path/outside/repo/swanlab.env"
```

下面每一项的命令单独使用。四卡、八卡正式服务器均通过 `--no-tmux` 前台启动；SwanLab 使用公开的 `TCPO` Project，按模型名称分组。

训练集统一在抽样前剔除缺失、`null` 或空白 `answer` 的记录，保留数字 `0` 等有效答案。若需清理训练集文件本身，可先运行：

```bash
"${FRUGALOPL_PYTHON}" scripts/clean_training_answers.py data/openthoughts_math30k.json
```
